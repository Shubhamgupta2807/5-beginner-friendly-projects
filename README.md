### 1️⃣ Daily Task Management App  
A simple command-line task manager that allows users to:
- Add tasks  
- Update tasks  
- Delete tasks  
- View all tasks  

**Concepts Used:**  
`Lists`, `Functions`, `Loops`, `Conditional Statements`, `User Input`

### 2️⃣ Password Guessing Game  
A fun game where the user selects a difficulty level (Easy, Medium, Hard), and the program randomly selects a secret word.  
The player must guess the password within limited attempts, with hints shown after wrong guesses.

**Concepts Used:**  
`Random Module`, `Lists`, `Loops`, `Conditionals`, `String Comparison`

---

### 3️⃣ Calculator with History  
A command-line calculator that performs basic arithmetic operations and stores calculation history in a file.

**Features:**
- Perform +, -, *, /  
- View calculation history  
- Clear history  
- Exit program  

**Concepts Used:**  
`File Handling`, `Functions`, `Loops`, `Basic Math`, `User Input`

---

### 4️⃣ Contact Book

- View all contacts  

**Concepts Used:**
